# Lüfterprojekt (ESP32-H2)

Lüftersteuerung mit ESP32-H2: Ein 3-Pin 12-V-PC-Lüfter wird per PWM gesteuert, die Drehzahl wird über ein selbst aufbereitetes Tachosignal vom Tachopin gemessen. Bedienung und Anzeige gibt es am Gerät und parallel in einem Webinterface im Browser (ESP32-H2 ↔ Node.js-Server ↔ Browser).

> **Status: in Arbeit.** Das Projekt funktioniert, die Dokumentation und das Aufräumen sind aber noch nicht abgeschlossen.
